# 场景预设 Schema（写预设只认这一份）

一个预设 = 一个 ES module，`export default` 一个对象。**不要 import three、不要写函数、不要碰 DOM**，
只填数据。引擎（`engine/builder.js`）负责把数据变成 three.js 场景图。

## 顶层

```js
export default {
  id: 'city_street',              // 小写下划线，唯一
  name: '城市街道',                // 中文名，出现在工作台列表
  desc: '双向车道 + 人行道 + 两侧楼房',   // 一句话
  unit: '米',                      // 固定写 '米'
  ground: { size: [44, 44], m: 'road' }, // 可选；不写就没有大地面
  sky: '#101014',                  // 可选；本场景推荐背景色（深色主题下用）
  lights: [ ... ],                 // 见下
  objects: [ ... ],                // 见下，主体内容
  cameras: [ ... ],                // 推荐机位，工作台一键跳
  marks: [ ... ]                   // 可选：走位标记
}
```

坐标系：**Y 轴向上，1 单位 = 1 米，人高按 1.75 米算**。
`p` 是物体**中心**（不是底面），所以一个 2 米高的柜子要写 `p:[x, 1.0, z]`。
`plane` 例外：`p` 是它的中心、贴地，`y` 一般写 0。

## lights

```js
lights: [
  { t: 'sun', dir: [-0.5, 1, 0.35], intensity: 1.15 },  // dir = 光"从哪来"的方向向量，不用归一化
  { t: 'amb', intensity: 0.5 },                          // 环境光
  { t: 'point', pos: [-4, 2.6, 3], intensity: 12, color: '#ffd9a0' } // 可选：吊灯这类点光，intensity 是 three 物理单位
]
```

`dir` 会被逻辑体检用来判「相邻镜头光源方向是否打脸」，**每个预设必须有一条 sun**。

## objects —— 六种图元

| t | 必填 | s 的含义 | 备注 |
|---|---|---|---|
| `box` | `p` `s` | `[宽, 高, 深]` | 主力，白膜就靠它 |
| `cyl` | `p` `s` | `[上半径, 下半径, 高]` | 第 4 位可选，填分段数（默认 20） |
| `sphere` | `p` `s` | `[半径]` | |
| `plane` | `p` `s` | `[宽, 深]` | 水平面，贴地用 `y=0` |
| `group` | `p` `children` | — | `children` 里的 `p` 相对本组原点 |
| `figure` | `p` | `[身高]` 可选，默认 1.75 | 圆柱身 + 球头人，**`p` 是脚底中心**（不是重心） |
| `mark` | `p` | `[半径]` 可选，默认 0.32 | 地上的一圈走位标记线，不算实体 |

通用可选字段：

- `n: '楼_A1'` —— 名称。**强烈建议每条都写**：大纲树、体检报告、提示词包全靠它。命名用「类别_编号」，中文可以。
- `rot: [rx, ry, rz]` —— 弧度，绕自身中心旋转。
- `m: 'building'` —— 语义材质名，见下表。**白膜的层级感就靠它**。
- `kind: 'wall'` —— 覆盖引擎的自动分类（见体检）；不写就按材质推断。
- `hang: true` —— 声明"它是吊着的"（吊灯、吊扇、挂在梁上的东西）。写在 `group` 上会**往下继承**给子件。
- `scope: 'background'` —— 远景层（天际线、远处的楼群）。写了就**不查越界、不查悬空**，因为它本来就在场地外几十米。
- `hidden: true` —— 建但不显示（留给"这个镜头不该出现"的对照）。
- `figure` 专用：`pose: 'stand'`、`action: 'walk'`、`facing: 1.57`（弧度，朝哪）、`seatY: 0.45`（坐面高度）。

## 语义材质表（只能用这些名字）

| 名字 | 用途 | 亮度档 |
|---|---|---|
| `ground` | 泥地/室外大地面 | 1 |
| `floor` | 室内地板 | 2 |
| `road` | 车行道 | 1 |
| `sidewalk` | 人行道 | 3 |
| `building` | 楼体块 | 2 |
| `wall` | 墙/隔断 | 3 |
| `furniture` | 桌椅柜床 | 4 |
| `prop` | 小道具/树干/栏杆 | 5 |
| `foliage` | 树冠/绿植 | 5 |
| `glass` | 窗/玻璃幕墙 | 6（半透明） |
| `person` | 人 | 7（强调） |
| `accent` | 主角/要拍的东西 | 8（强调，全场景最多 3 个） |
| `mark` | 走位点/胶带 | 9（线框） |

## cameras —— 推荐机位

```js
cameras: [
  { n: '机位1_街道纵深', pos: [-3, 1.6, 15], look: [0, 1.4, -12], mm: 35 },
  { n: '机位2_低角度跟拍', pos: [2, 0.5, 8], look: [0, 1.0, -6], mm: 28 }
]
```

`pos`/`look` 都是米。`mm` 是全画幅等效焦段（24/28/35/50/85 常见），工作台会换算成 FOV。
**至少给 4 个机位，且互相不要越轴**（相邻机位保持在被摄主体同一侧）。

## 硬性约束（`node tools/validate.mjs presets/x.js` 逐条查；下面是 `engine/checks.js` 的**真实**判据，不是理想条文）

1. **越界**：物体的**中心**要落在地面范围内（容差 10 厘米）。贴边站的墙中心正好在边上，算合规。
   远景楼群请写 `scope: 'background'`，否则必然报（它本来就在几十米外）。
2. **悬空**：底面离地 > 5 厘米，且四个方向 4 厘米内没有任何物体贴着 → 报。
   所以贴在墙上的电视、压在桌面上的水杯都算合规；真吊着的（吊灯、吊扇）写 `hang: true`。
   底面插进地里超过 5 厘米报 `sunk`。
3. **穿模**：跨 group 的两个实体，重叠体积超过**小的一方** 25% 才报。
   **一件家具的多个部件请务必写成 `t:'group'`** —— 同一 group 内部件互相穿插是白膜的正常建模手法（座面和扶手本来就该接在一起），引擎不报；跨 group 才报。
4. **重名**：报错。
5. **数量**：12~60 件是舒适区；少于 12 件提醒"画面会空"；多于 220 件提醒体检和逐帧渲染会变慢。
6. 必须有 1 条 `sun`、至少 4 个 `cameras`（机位还会单独查：埋在物体/人里面 = 报错，看出去是空的 = 提醒，贴地 = 提醒）。
