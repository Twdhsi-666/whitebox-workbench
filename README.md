# 椰子工作台 · AI 视频白膜预演台

**先把这场戏排明白，再交给 AI 去画。**

在生成式视频里，你写三千字提示词，模型照样让人物往反方向走、让镜头乱飘。
这个工作台的做法是：**先用米制白膜把空间搭出来，把机位、走位、时长全部定死，逐帧渲成一段"丑但准确"的白膜视频，把它当运镜与空间参考喂给视频模型。**
白膜用 HTML + three.js 写，不碰 C4D / Blender —— 语言模型能直接生成、能 diff、能进 Git，成本极低。

## 工作流（左到右就是顺序）

| 步 | 做什么 | 在哪 |
|---|---|---|
| ① | 选场景预设（城市街道 / 黄昏天台 / 教室 / 中餐馆 / 卧室 / 客厅 / 办公室），或自己加方块 | 左栏 |
| ② | 加人物（圆柱身 + 球头），选动作，在地面上**画一条线**就是走位路线 | 左栏 + 视口 |
| ③ | 把画面调到想要的景别 → 「＋ 从当前视角加机位」→ 选运镜、时长、焦段、缓动 | 右栏 |
| ④ | 看逻辑体检，红条必须先解决 | 右栏 |
| ⑤ | 生成提示词包 → 一键出片 | 右栏 / 顶栏 |

出片产物落在 `输出/<工程名>_<时间戳>/`：`xxx.mp4` + `首帧/镜头N.jpg`（每张就是一个镜头的分镜参考图）。

## 相机这块做到多细

- **焦段** 14 / 21 / 24 / 28 / 35 / 40 / 50 / 65 / 85 / 100 / 135mm，按全画幅 36mm 感光宽换算成垂直 FOV，滑杆和下拉双向联动，实时显示角度。
- **画幅** 16:9 / 9:16 / 4:3 / 1:1 / 4:5 / 1.85:1 / 2.39:1，用 scissor 做**真遮幅**（不是把画面拉伸），出片分辨率跟着画幅走。
- **导航** 右键环绕、滚轮推拉、`W A S D` 飞行 + `Q E` 升降（`Shift` 加速）、`1 3 7 9` 前/右/顶/后（`Ctrl` 反向，主键盘数字，笔记本没小键盘也能用）、`0` 切相机视角、`.` 聚焦选中、`G` 拖动选中人物。
- **运镜预设 19 条**：固定、推进、拉出、左右横移、升降、俯冲、左右环绕、360° 一镜到底、左右摇、上摇、滑动变焦、甩镜、跟随（可锁人物胸口）、手持抖动、A→B 自定义、黑场起。缓动曲线逐条取自 tween.js 的 `src/Easing.ts`（源码留档在 `vendor/easing/`）。
- **两种衔接**：硬切换（每镜头单独生成再剪）/ 一镜到底（段间做混合过渡，默认 0.8 秒）。

## 逻辑体检在查什么

不是"看着像不像"，是拿坐标算：

- 机位埋在墙里 / 人里 → 拍到的是黑屏（阻断）
- 镜头看出去 60 米内正前方和视野四角都没东西 → 空镜头
- 相邻镜头主体从画面右边跳到左边 → **越轴**；走位方向翻转同样报
- 相邻机位差不到 0.5 米、焦段也接近 → 剪起来像没换机位
- 主光方向在两个镜头之间转了 55° 以上 → 脸的明暗会跳
- 物体悬空 / 插地 / 超出地面 / 跨组穿模 / 重名 / 段长短于 0.5 秒
- 体检条目可点击，直接跳到出问题的那个物体或镜头

判据是按白膜的真实习惯定的：贴在墙上的电视、放在桌上的药盒、同一件家具互相穿插的部件，都**不算** bug（详见 `docs/场景预设Schema.md`）。

## 两种模式

| | 在线（GitHub Pages，纯静态） | 本地（`启动工作台.bat`） |
|---|---|---|
| 摆场景 / 人物走位 / 运镜 / 画幅 / 体检 / 提示词包 | ✅ | ✅ |
| 出片 | 退化成实时录制 webm | ✅ 逐帧渲染 → 本机 ffmpeg → H.264 MP4 |
| 工程保存 | 浏览器 localStorage + 导出 JSON + 编进网址分享 | 同左，另存 `输出/` |

页面启动时探测本地服务，模式写在顶栏徽章上，不会静默降级。

## 目录

```
index.html  css/  app/          工作台外壳与界面
engine/     builder checks camera figure easing   场景构建、体检、相机、人物、缓动
presets/    *.js                                   米制场景预设（数据，不是代码）
vendor/     three.module.js + easing 留档
tools/      validate.mjs（预设体检） shot.mjs（界面自检）
server.mjs  静态服务 + 收帧 + 调 ffmpeg
docs/       场景 Schema / 给语言模型的提示词 / 决策记录
```

新增一个场景不用写代码：照 `docs/场景预设Schema.md` 写一个数据文件放进 `presets/`，
跑 `node tools/validate.mjs presets/xxx.js` 到 0 错，再在 `presets/index.js` 登记一行。
**这个文件就是给语言模型写的**——把 Schema 丢给它，让它直接产出场景。

## 已知不足（别当成已实现）

- **一张图生成 3D 空间** 做不到。在线服务能传参考图自动出白模，我们只能靠预设和语言模型生成数据。
- **景深/光圈** 没有，只有焦段。虚化要加后期通道。
- 走位目前只有"画线"，逐点标记和时间轴拖关键帧还没做。
- 人物动作是程序化的（走/跑/坐/递/咳嗽/指/弯腰…），**不是**任意动作；打斗、手指细节控不住。
- 在线模式的 webm 能不能被各家视频模型直接收，我没验证。要稳就走本地模式出 MP4。
- 体检对超大场景（>220 件）会变慢，远景层的遮挡判断仍是包围盒近似。

## 自检清单（我验过什么）

- 7 个预设 `tools/validate.mjs` 全部 0 错 0 警。
- headless Edge + CDP 实开页面点完主流程，**页面报错 0 条**（`tools/shot.mjs`）。
- 一键出片实测：263 帧 / 13 秒 / 输出 10.52 秒 1080×1920 H.264 25fps 1.5MB + 5 张首帧图。
- 界面截图我逐张看过：修掉了右栏裁切、视锥糊屏、初始视角看墙背、人物全橙不分主次。
- 没验的：导出 JSON 的往返、分享链接超长降级、浅色主题下的长时间使用、体检条目点击定位到远景层。
