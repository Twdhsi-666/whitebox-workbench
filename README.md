# 白膜工作台 · Whitebox Workbench

> AI 视频生成前的「3D 白膜」创作台：**从零搭白膜场景，或导入任意 AI 生成的白膜 HTML——在 Cinemap 风 3D 地球上统一管理、播放、跳转、截图。**

解决什么问题：用 HTML 做 3D 白膜来理顺 AI 视频的镜头逻辑，成本极低、语言模型也能生成——但每个 AI 产出的 HTML 格式都不一样，无法统一控制。本工作台定义了一份**《白膜 HTML 规范 v1.0》**，并内置**兼容层**：旧格式文件直接拖进来也能用。v2 起内置**原生白膜场景编辑器**：不写一行代码，用预设环境 + 预设建模直接搭镜头。

## 功能

**白膜场景编辑器（v2 新增）**

- **预设环境入口**：空房间 / 街道 / 神庙 / 办公室 / 荒野 / 影棚，6 种开箱即用的白膜环境
- **轨道相机**：左键旋转、右键/Shift 平移、滚轮缩放，带阻尼；空白处拖动环视，点选物体后在地面平面拖拽移动
- **预设建模资产坞**：33 个程序化白膜资产（人物 5 / 载具 3 / 建筑 8 / 自然 5 / 道具 12），点击即放入画面，离屏渲染缩略图
- **属性检查器**：位置 / 旋转 / 缩放数值微调，8 色黏土涂装，一键复制
- **机位管理**：全景 / 中景 / 近景 / 特写四档景别，保存任意机位随时跳回，相机过渡动画
- **自动保存**：返回入口时脏检查自动保存，场景存 localStorage，入口「我的场景」直接重开续编辑

**白膜 HTML 管理台（v1）**

- **一键导入**：拖拽 / 选择 `.html` 文件，或项目 `.json` 备份
- **3D 地球视图**（复刻 Cinemap 视觉）：星空 + 点阵大陆 + 大气辉光；每个场景一枚标记——有经纬度的按位置落点（琥珀色），没定位的沿赤道「故事环」排布（青色）
- **统一播放器**：播放/暂停、进度拖拽、分镜刻度、倍速（兼容层）、逐帧截图下载、全屏
- **规范校验**：导入时逐项检查 manifest 与 10 个标准接口，报告缺失项
- **旧文件兼容层**：自动隐藏旧面板、画布铺满、虚拟时钟接管播放/暂停/跳转/截图（精确到 0.1s）
- **离线可用**：Three.js 本地镜像，导入时自动把 CDN 依赖重写成本地文件
- **本地持久化**：场景存 localStorage，支持导出/导入项目 JSON
- **规范即入口**：内置规范文档 + 一键复制「AI 提示词」+ 模板/示例下载

## 快速开始

**方式一：本地启动（推荐）**
双击 `启动.bat` → 自动起本地服务器并打开浏览器（仅监听 127.0.0.1，不上传任何数据）。

**方式二：在线版**
打开 <https://twdhsi-666.github.io/whitebox-workbench/>

**方式三：命令行**
```bash
python -m http.server 8123        # 或 node server.js
# 浏览器打开 http://127.0.0.1:8123/index.html
```

> 必须通过 http:// 访问（不能直接双击 index.html）：导入的场景以 blob iframe 同源加载，file:// 下浏览器会拦截。

## 导入自己的白膜 HTML

1. 直接把 `.html` 文件拖进工作台窗口；
2. 工作台自动分级：**规范文件**（完整控制）/ **兼容导入**（旧文件自动适配）；
3. 点场景卡片或地球标记即可播放。

## 让其他 AI 生成可导入的白膜 HTML

把 `spec/AI提示词.md` 整段复制，连同你的场景需求发给任意 AI（DeepSeek / ChatGPT / Claude / 通义……），它返回的 HTML 就能直接拖进工作台。

规范核心（详见 [spec/白膜HTML规范.md](spec/白膜HTML规范.md)）：

1. 单个自包含 `.html`，Three.js 是唯一依赖（importmap 引入，工作台自动重写为本地镜像）；
2. `#stage` 16:9 舞台 + 可选 `#panel`；
3. `</body>` 前放 `#whitebox-manifest` 元数据（标题/时长/定位/分镜）；
4. 实现 10 个标准接口：`__ready / __seek / __grab / __size / __glOk / __play / __pause / __playing / __duration / __getTime`；
5. `window.__EMBED__ === true` 时隐藏自己的面板、画布铺满、不自动播放。

## 兼容层是怎么工作的

对不满足规范的旧文件，导入时会向 `<head>` 注入一段桥接脚本：

- 打补丁 `performance.now` / `Date.now` / `requestAnimationFrame`，把真实时间换成**虚拟时钟**——旧文件的动画时间基准通常就是这两个值，于是播放/暂停/跳转/倍速全部可精确控制；
- 读取旧面板上的时间显示来校准时间轴（0.1s 精度），读取 `[data-jump]` 按钮来补全 manifest 分镜；
- 包装 rAF，在旧场景渲染后的同一帧内截图（解决未开 `preserveDrawingBuffer` 的丢帧问题）；
- 自动隐藏旧面板、让画布铺满容器。

精度排序：**规范文件 > 有面板显示的旧文件 > 无时间显示的旧文件**（后者仅支持播放/暂停）。
